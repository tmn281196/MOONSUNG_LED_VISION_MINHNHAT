LED COLOR INSPECTION – การตรวจสี LED ด้วยเกณฑ์ช่วงสี HSV
=========================================================

1. แปลงภาพจากกล้อง (BGR) เป็น HSV
   H = โทนสี 0–179, S = ความสด 0–255, V = ความสว่าง 0–255 (สเกล OpenCV)
   ใช้ HSV เพราะโทนสี H ของ LED แทบไม่เปลี่ยนเมื่อแสงหรือ exposure เปลี่ยน
   ส่วน S แยก LED ที่ติด (สีสด) ออกจากพื้นหลัง และ V min ตัด LED ที่ดับออก

2. ตั้งช่วงสีให้ LED แต่ละกลุ่ม: Hmin–Hmax, Smin–Smax, Vmin–Vmax
   ค่า Hue โดยประมาณ: แดง 0 หรือ 175–179, ส้ม 10–20, เหลือง 25–35, เขียว 55–75,
   ฟ้า 85–95, น้ำเงิน 110–130, ม่วง/ชมพู 145–165

3. เกณฑ์ช่วงสี (inRange): พิกเซล p ผ่านก็ต่อเมื่อทั้งสามเงื่อนไขเป็นจริงพร้อมกัน
      Hmin ≤ H(p) ≤ Hmax  และ  Smin ≤ S(p) ≤ Smax  และ  Vmin ≤ V(p) ≤ Vmax
   ผลคือ mask ขาว/ดำ: ผ่าน = 255, ไม่ผ่าน = 0

4. ใน ROI (วงกลม) ของ LED แต่ละดวง นับพิกเซลที่ผ่าน
      จำนวน > Area  →  LED ติดและสีถูกต้อง (OK)
      จำนวน ≤ Area  →  NG
   Area คือจำนวนพิกเซลขั้นต่ำ ตั้งไว้ประมาณครึ่งหนึ่งของพื้นที่สว่างตอน LED ติดปกติ

วิธีหาค่า: เปิด LED ดูฮิสโทแกรม H/S/V ของ ROI ในหน้า Vision ตั้ง min/max ล้อมยอดของกราฟ
(H ±8, S min ≈ 80–120, V min ≈ 100–150, max = 255) แล้วดับ LED ตรวจว่าจำนวนพิกเซลผ่าน
ต่ำกว่า Area สีที่ Hue ใกล้กันให้แยกกลุ่มและบีบช่วง H ให้แคบ
