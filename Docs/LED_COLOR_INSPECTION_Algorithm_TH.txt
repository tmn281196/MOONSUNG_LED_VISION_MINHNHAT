LED COLOR INSPECTION – คำอธิบายอัลกอริทึมของโปรแกรม
=====================================================

1. ภาพรวม
----------
โปรแกรมใช้กล้อง (Logitech BRIO) ถ่ายภาพแผง LED ของชิ้นงาน แล้วตรวจว่า LED แต่ละดวง
"ติดและมีสีถูกต้อง" หรือไม่ โดยไม่ต้องใช้เซ็นเซอร์แสงหรือวงจรวัดกระแส
การตรวจแบ่งเป็น 3 ชั้น

  ชั้นที่ 1  พิกเซล   : แปลงภาพเป็น HSV แล้วคัดพิกเซลที่อยู่ในช่วงสีที่ตั้งไว้
  ชั้นที่ 2  ROI      : นับพิกเซลที่ผ่านในวงกลม ROI ของ LED แต่ละดวง เทียบกับเกณฑ์พื้นที่
  ชั้นที่ 3  เวลา     : ROI ต้องผ่านต่อเนื่องครบเวลา Hold ภายในเวลา Timeout จึงถือว่า OK

การทดสอบหนึ่งรอบถูกกำหนดด้วย "ลำดับ step" (Sequence) ที่บันทึกอยู่ในไฟล์โมเดล
ประกอบด้วยการจ่ายไฟ (POWER), การสั่งรีเลย์ (RELAY), การหน่วงเวลา (DELAY)
และการตรวจด้วยกล้อง (VISION CHECK) ทีละกลุ่ม LED


2. โมเดล (Model)
----------------
ไฟล์โมเดล (.json) หนึ่งไฟล์ต่อชิ้นงานหนึ่งรุ่น เก็บ

  - กลุ่ม LED (Group) จำนวนเท่าใดก็ได้ ผู้ใช้ตั้งชื่อเอง เช่น L-7SEG, R-7SEG, U-5DOT
    แต่ละกลุ่มมี
      • ROI : วงกลมหนึ่งวงต่อ LED หนึ่งดวง (ตำแหน่ง x,y และรัศมี)
      • ช่วงสี HSV : H min–max, S min–max, V min–max
      • Radius : รัศมี ROI (พิกเซลบนภาพแสดงผล)
      • Area   : เกณฑ์พื้นที่สว่างขั้นต่ำ (จำนวนพิกเซลที่ผ่านช่วงสี)
  - ค่าตั้งกล้อง (Exposure, Gain, White balance, Zoom, Focus, Pan/Tilt …)
    ซึ่งจะถูกเขียนลงกล้องทันทีเมื่อเปิดโมเดล
  - ลำดับ step ของการทดสอบ


3. การตรวจสีในหนึ่งเฟรม (ชั้นพิกเซลและชั้น ROI)
------------------------------------------------
สำหรับ ROI แต่ละวงในกลุ่มที่กำลังตรวจ

  1) ตัดภาพสี่เหลี่ยมรอบวงกลม ROI จากเฟรมกล้อง
  2) แปลง BGR → HSV
  3) inRange(H min..H max, S min..S max, V min..V max) ได้ mask ขาว/ดำ
     (สเกล OpenCV: H 0–179, S 0–255, V 0–255)
  4) AND กับ mask วงกลม เพื่อเอาเฉพาะพิกเซลในวง ROI
  5) นับพิกเซลขาว = "พื้นที่สว่างที่มีสีถูกต้อง"
  6) ถ้าจำนวนพิกเซล > Area ของกลุ่ม → ROI นี้ OK ในเฟรมนี้ (วงเขียว)
     ไม่เช่นนั้น → NG ในเฟรมนี้ (วงแดง)

เหตุที่ใช้ HSV: ค่า Hue ของ LED แทบไม่เปลี่ยนเมื่อ exposure หรือแสงแวดล้อมเปลี่ยน
ต่างจาก RGB ที่เปลี่ยนพร้อมกันทั้งสามค่า ค่า S คัด LED ที่ติด (สีสด) ออกจากพื้นหลัง
และค่า V min คือตัวตัด LED ที่ดับ


4. การตัดสินตามเวลา (ชั้นเวลา) – step VISION CHECK
---------------------------------------------------
step VISION CHECK มีสองพารามิเตอร์

  Hold    (ms) : ROI ต้อง OK ต่อเนื่องนานเท่านี้จึงถือว่า OK จริง
                 ว่างหรือ 0 = OK เพียงเฟรมเดียวก็พอ
  Timeout (ms) : เวลารอสูงสุด (ค่าเริ่มต้น 2000)

การทำงาน (กล้องเก็บตัวอย่างทุก 100 ms)

  - ทุกตัวอย่าง ตรวจ ROI ทุกวงตามข้อ 3
  - ROI แต่ละวงนับจำนวนตัวอย่าง OK ที่ต่อเนื่องกัน ถ้าเจอ NG ตัวนับกลับเป็น 0
  - เมื่อจำนวน OK ต่อเนื่อง × 100 ms ≥ Hold → ROI นั้น "ถึง Hold แล้ว"
  - ทันทีที่ ROI ทุกวงถึง Hold → step PASS และจบก่อนหมด Timeout
  - หมด Timeout แล้วยังมี ROI ที่ไม่เคยถึง Hold → step FAIL (ROI เหล่านั้นแดง)

ตัวเลือกในหน้า Setting ("VISION CHECK pass rule") ถ้าไม่ติ๊ก จะใช้กฎเข้มงวดแทน:
ROI ทุกวงต้อง OK ในทุกตัวอย่างตลอด Timeout

ในหน้า Vision (ดูสด) มีช่อง Hold เดียวกันไว้ทดลอง: ROI จะเป็นสีเขียวเมื่อ OK ต่อเนื่อง
ครบเวลาที่ตั้ง (จังหวะดูสด 250 ms) ใช้หาค่า Hold ที่เหมาะสมก่อนใส่ใน step


5. ลำดับการทดสอบ (Sequence)
---------------------------
step มี 4 ชนิด รันจากบนลงล่าง

  POWER ON/OFF           : รีเลย์ไฟ 220 V ของชิ้นงาน (IO Box ยอมให้ ON เฉพาะตอนกระบอกลมอยู่ล่าง)
  RELAY ON/OFF  Target   : รีเลย์อเนกประสงค์ 1–5 (Target ว่าง = ทั้ง 5 ตัว)
                           ใช้จ่ายไฟขาร่วมของแผง LED แบบสแกนทีละกลุ่ม
  DELAY  Spec            : รอ (ms) คอลัมน์ Value นับเวลาขึ้นทุก 10 ms
  VISION CHECK Target    : ตรวจกลุ่ม LED ตามชื่อ ด้วย Hold/Timeout ตามข้อ 4

กฎ
  - step ที่ FAIL ไม่หยุดลำดับ step ที่เหลือยังรันต่อเพื่อให้เห็นจุดเสียทั้งหมด
    ผลรอบ = NG ถ้ามี step ใด FAIL
  - step ที่ติ๊ก Skip จะข้ามไป
  - ระหว่าง VISION CHECK จะแสดงเฉพาะ ROI ของกลุ่มนั้น จบ step แล้วซ่อน
    จบรอบทดสอบจึงแสดง ROI ทั้งหมดพร้อมสีผลลัพธ์ (เขียว OK / แดง NG / เทา ไม่ได้ตรวจ)

ตัวอย่างลำดับสำหรับแผง LED สแกน 3 กลุ่ม
  1 POWER ON
  2 RELAY 1 ON
  3 VISION CHECK L-7SEG  (Hold 300, Timeout 2000)
  4 RELAY 1 OFF
  5 RELAY 2 ON
  6 VISION CHECK R-7SEG
  7 RELAY 2 OFF
  8 RELAY 3 ON
  9 VISION CHECK U-5DOT
 10 RELAY 3 OFF
 11 POWER OFF


6. รอบการทดสอบในหน้า Auto
-------------------------
  1) ทริกเกอร์ : เซ็นเซอร์ DOWN ของกระบอกลมเปลี่ยนจาก "ไม่ลง" เป็น "ลงสุด"
     (ขอบขาขึ้นเท่านั้น สถานะแรกหลังเปิดพอร์ตไม่นับ) หรือกดปุ่ม START
  2) ก่อนเริ่ม : ส่ง POWER OFF และปิดรีเลย์ทั้งหมด ล้างผลของ step ทุกตัว
  3) รอเซ็นเซอร์ DOWN ยืนยันว่าลงสุด (ไม่เกิน Sensor timeout)
  4) รันลำดับ step ตามข้อ 5 นาฬิกา Takt รวมเดินตั้งแต่ทริกเกอร์
  5) ผล
       PASS : ปิดไฟ ปิดรีเลย์ ยกจิ๊กขึ้น นับ PASS
       NG   : ปิดไฟ ปิดรีเลย์ จิ๊กอยู่ล่าง นับ FAIL แสดงหน้าต่างภาพผลลัพธ์
              ถ้าตั้ง Retest times > 0 จะยกจิ๊กขึ้นแล้วลงใหม่และทดสอบซ้ำก่อนสรุปเป็น NG
  6) หลังจบ 1.5 วินาที จึงรับทริกเกอร์ใหม่ (กันสัญญาณค้างจากกระบอกลม)

การยกเลิก
  - กด EMERGENCY STOP หรือกระบอกลมออกจากตำแหน่งล่างระหว่างทดสอบ → หยุดทันที
    ไม่นับผล ปิดไฟและรีเลย์ทั้งหมด
  - เมื่อกระบอกลมออกจากตำแหน่งล่างเวลาใดก็ตาม ทั้ง IO Box และโปรแกรมจะปิด POWER
    และรีเลย์ 1–5 เอง


7. ภาพผลลัพธ์และ log
--------------------
  - ทุก step VISION CHECK ที่จบลง โปรแกรมจะบันทึกภาพหน้าจอกล้อง (ภาพจริง + วง ROI สีเขียว/แดง)
    ไว้ในหน่วยความจำ
  - จบรอบ ภาพเหล่านี้ถูกต่อกันเป็นภาพเดียว (สูงสุด 4 ภาพต่อแถว) แต่ละภาพมีแถบชื่อ step
    ค่าที่ได้ และ PASS (เขียว) / FAIL (แดง) รอบทดสอบซ้ำจะมีข้อความ (retest n)
  - ภาพนี้แสดงในหน้าต่าง "Test result" (เปิดเองเมื่อ NG หรือกดปุ่ม RESULT ปิดเองเมื่อเริ่มทดสอบใหม่)
    และบันทึกเป็น JPG ในโฟลเดอร์ Log ตามที่ติ๊กไว้ในหน้า Setting (NG / PASS)


8. การสื่อสารกับ IO Box (Arduino Mega)
--------------------------------------
เฟรม 5 ไบต์ทั้งสองทิศทาง: [cmd][key][value][chk][0x11], chk = cmd XOR key XOR value

  SET   0x52 : สั่งเอาต์พุต 1 ตัว (0 POWER, 1 UP, 2 DOWN, 3–7 RELAY1–5) บอร์ดตอบเฟรมเดิม
  GET   0x49 : อ่านอินพุต (2 = เซ็นเซอร์ DOWN) บอร์ดตอบ 1 เฟรมต่อ 1 อินพุต
  RESET 0xD5 : ปิดเอาต์พุตทั้งหมด
  EVENT      : บอร์ดส่ง 49 02 level chk 11 เองทุกครั้งที่เซ็นเซอร์ DOWN เปลี่ยน (debounce 50 ms)

อินเตอร์ล็อกในเฟิร์มแวร์: POWER เปิดได้เฉพาะตอนเซ็นเซอร์ DOWN ทำงาน และเมื่อเซ็นเซอร์หลุด
บอร์ดจะตัด POWER และรีเลย์ 1–5 ทันทีโดยไม่รอคำสั่งจาก PC


9. แนวทางตั้งค่าให้ผลเสถียร
----------------------------
  - ตั้งกล้องด้วยค่าคงที่ (ปิด Auto exposure / Auto WB / Auto focus) แล้วบันทึกลงโมเดล
  - ใช้ฮิสโทแกรม H/S/V ในหน้า Vision: ตั้งช่วง H ล้อมยอดสีของ LED (±8) S min ≈ 80–120
    V min ≈ 100–150 แล้วตรวจว่าตอน LED ดับ พื้นที่สว่างต่ำกว่า Area
  - แผง LED แบบสแกน: บางเฟรมอาจจับตอน LED ดับ ให้ใช้ Hold สั้น (200–500 ms) กับ Timeout
    ที่ยาวพอ (1500–2000 ms) และจ่ายไฟทีละกลุ่มด้วยรีเลย์
  - สีที่ Hue ใกล้กัน (ส้ม/เหลือง) ให้แยกคนละกลุ่มและบีบช่วง H ให้แคบ
